SITEGUARD

07

The firmware in velxio.cpp is deliberately simple and robust. It captures a QVGA JPEG, posts it to the FastAPI server, and paces itself to 5 frames per second, subtracting the time the upload took. Two frame buffers in PSRAM with grab-latest mode mean the sensor captures the next frame while the current one uploads, and we always send the freshest image rather than a stale one. HTTP keep-alive reuses the TCP connection. The request carries the camera ID, name and location as headers, so adding a camera needs no server change. If the camera or Wi-Fi drops, the loop retries instead of crashing. We tested it in the Velxio ESP32 simulator as well as on hardware.
