When the engine confirms a violation, the event manager does three things. It saves the annotated frame as a JPEG, so every incident has photo evidence. It writes an incident row to SQLite running in write-ahead-logging mode, which lets the dashboard read while the pipeline writes without blocking. And it broadcasts an INCIDENT_ALERT message over WebSocket to every open dashboard. The fields shown are the real payload fields; the values are an example. Severity is configurable: missing helmet or vest is high, missing mask is medium. Cameras also send heartbeats with signal strength and free memory, and a camera silent for 15 seconds is marked offline.
