Gear belongs to the worker whose box contains it

Assigned when containment is 0.50 or more

11

The detector finds people and PPE separately, so we must decide which hardhat belongs to which worker. Following Fang et al., we measure containment: what fraction of the PPE box lies inside the person box. Using the PPE area as the denominator, not plain IoU, matters because a hardhat is tiny relative to a body. At 50 percent or more, the item belongs to that worker. Gear lying on the ground matches nobody and is ignored. If a worker has both a hardhat and a no-hardhat detection, the more confident one wins. The output is a per-worker checklist like the one on the right, keyed to the track ID, which feeds the safety engine. The values shown are an illustrative example.
