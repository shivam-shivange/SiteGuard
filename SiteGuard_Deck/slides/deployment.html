SITEGUARD

19

Today SiteGuard runs entirely on a local PC: no cloud bill, no internet dependency, low latency. Because the server is a standard FastAPI app with a pluggable model runtime, it can move up three paths without a rewrite. A Jetson Orin Nano gateway with TensorRT gives a rugged on-site box for eight or more cameras. A hybrid cloud deployment on AWS with Triton gives head-office oversight across many sites. Or a Docker Compose bundle with nginx, Redis and Postgres gives a one-command install for a site office.
